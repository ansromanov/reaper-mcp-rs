# Security policy

reaper-mcp-rs lets an AI agent control REAPER; see
[Security](https://ansromanov.github.io/reaper-mcp-rs/security.html) for what that allows and how
to limit it.

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/ansromanov/reaper-mcp-rs/security/advisories/new),
not in a public issue. Fixes go into the latest release.
